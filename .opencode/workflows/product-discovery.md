# Product Discovery

1. Intake request.
2. Router classifies task.
3. Product Manager creates `product/prd.json`.
4. Business Analyst creates `requirements/requirements.json` when domain rules matter.
5. Product Owner creates `requirements/acceptance-criteria.json`.
6. UX Researcher runs only when user flow/UI behavior is relevant.
7. Product Analyst runs only when measurable product outcomes matter.
8. Context Compactor normalizes verbose outputs.
9. Artifact Manager updates state.
