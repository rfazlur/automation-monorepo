# Feature Development

1. Product discovery artifacts must exist or be explicitly skipped.
2. Repo Scout creates `development/context-manifest.json`.
3. Technical PM creates `development/technical-scope.json`.
4. Architect creates `architecture/technical-design.json` for medium/high complexity.
5. Planner creates `development/implementation-plan.json`.
6. Developer implements only the scoped changes.
7. QA Lead and Test Designer create focused QA artifacts.
8. Automation Engineer/API/UI tester execute only relevant checks.
9. Failure Analyzer classifies failures.
10. Debugger repairs only when authorized; repeat with an escalation limit.
11. Code/Security/Performance reviewers run according to risk.
12. Release Manager summarizes evidence.
13. Release Gate evaluates required artifacts.
