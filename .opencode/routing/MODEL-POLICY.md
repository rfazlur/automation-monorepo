# Model Policy

- `combo-free`: discovery, file locating, artifact housekeeping.
- `combo-gemini`: structured analysis, product, requirements, QA, failure classification.
- `combo-sonnet`: orchestration, technical product work, standard implementation, release coordination.
- `combo-opus`: architecture, complex implementation/debugging, security/performance review, release gate.

Never solve an input-length problem by simply escalating the model. Reduce the context first.
